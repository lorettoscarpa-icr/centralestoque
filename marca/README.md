# Arquivos da marca — Loretto Scarpa

Coloque aqui as imagens da marca (leão, logomarca, versões preto/branco/dourado, selo, etc.).

Como usar:
- Adicione os arquivos de imagem nesta pasta (`.png`, `.jpg`, `.svg`, `.webp`).
- No app, abra a etiqueta → **Símbolo do leão → Galeria da marca**.
- Os arquivos desta pasta aparecem automaticamente: clique em **Usar leão** para
  aplicar como símbolo (vale para a loja e para as fábricas) ou **Baixar** para
  pegar o arquivo original e enviar para gráfica/fábrica.

Dica: dê nomes claros aos arquivos (ex.: `leao-dourado.png`, `logomarca-preta.svg`),
pois o nome aparece na galeria.
